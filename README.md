# Instagram User Analytics

## Overview
SQL-based analysis of Instagram user interactions and engagement 
data to identify behavior patterns and growth strategies.

## Files
- `Instagram_User_Analytics.sql` - All SQL queries
- `Commands_for_creating_Database.docx` - Database setup commands
- `user_1.txt` - Dataset used for analysis

## Tools Used
- SQL
- MySQL Workbench

## Key Insights
- Identified user activity and posting patterns
- Analyzed likes, comments, and engagement metrics
- Generated insights to optimize user retention
